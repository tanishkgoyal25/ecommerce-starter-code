This is an E-Commerce project built with Next.js as the client framework, Node.js as the runtime environment, Express.js as the server framework, and MongoDB as the database.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Inter](https://vercel.com/font).
